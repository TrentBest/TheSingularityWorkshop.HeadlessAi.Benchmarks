## Documentation authority

This repository follows the [FSM_COS Documentation Standard](https://github.com/TrentBest/TheSingularityWorkshop.FSM_COS/blob/development/DOCUMENTATION_STANDARD.md). The HeadlessAi repository owns the library API and behavior; this repository owns its measurement harness and methodology.

A planned benchmark is not a measured result. Source, tests, and retained run artifacts should support every performance claim.
